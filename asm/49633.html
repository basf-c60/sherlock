C1E1: Print gatekeeper: check two flags, then dispatch
Checks $5C3C first; if it's zero, returns immediately, printing nothing.
Input
A The character
Output
The character printed in the command window or the text window, as the flags $5C3C and $A027 say
C1E1 PUSH AF Save the character to print
C1E2 LD A,($5C3C) Is output enabled at all right now?
C1E5 AND A Test A for zero (this leaves A as it was and clears carry)
C1E6 JR NZ,$C1EA If A is not zero, skip ahead to C1EA
C1E8 POP AF No: print nothing
C1E9 RET Return to the caller
C1EA LD A,($A027) Are we in the other, quote/case-folding mode?
C1ED AND A Test A for zero (this leaves A as it was and clears carry)
C1EE JR NZ,$C1FC If A is not zero, skip ahead to the routine "Echo a typed character in the command window" (C1FC)
C1F0 POP AF No: print the character the plain way
C1F1 JP $C2BA Jump on to the routine "Print one character (or handle a newline) at the..." (C2BA)
