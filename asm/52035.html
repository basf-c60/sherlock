CB43: End of an actor's go: hand the turn back to the player
Reached from $C9A2. Unless DC6C says otherwise, makes the first actor in the table (9860, the player) current again; when $A00B is set, either clears $A00C and narrates (CA76) or - with HL not zero - calls HL with $A027 set (CB40).
How it works:
1. If the actor is the player, Watson or the police cab (actors 0, 1 or $64), do nothing.
2. Otherwise note a failure ($A00B): either call the failure routine given in HL or narrate that the action failed (CA76).
3. Make the player the current actor again.
Input
HL The failure routine to call, or 0
Output
