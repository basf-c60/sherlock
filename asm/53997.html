D2ED: Total size (+2) of the things directly in thing A
D305 with B = 1: adds the size byte (+2) of every thing whose container (+1) is A; C = $FF if it goes over 127. The fit check at DEE4 compares this with the container's capacity ($DEF8).
Input
A the container
Output
A the total
