C1C0: Print a prompt at HL, wait for a key, newline
C1CB, then C415, then a newline. The save and load routines use it with HL pointing into the ROM's own tape messages ($09A2, $09AC, $09B2).
Input
HL A message ending with bit 7 set
Output
The message printed, a key waited for and a new line started
