DF7E: Sub-script: shared action 20, TAKE the burning note
TAKE it (DCC1), then DF8B.
Entry points: DF80 = body of record DF7E.
Each sub-block is one instruction. Room and object numbers are as the game uses them (the reference pages list both).
In an instruction, 'plan dobj' and 'plan iobj' are not fixed objects: they mean the direct and indirect object currently held in the actor's plan registers (bytes +4 and +5 of its actor record), so the same step works on whatever the actor is dealing with - for the player, the objects of the command just typed. 'plan verb' is the verb register (+3), 'self' is the acting character, and '-' means none.
DROP BURN NOTE then a plain TAKE BURN NOTE runs this script - the countdown 9CA1 goes to $FF and the note is called SINGE; EXAMINE CLOSELY SINGE NOTE then counts as examining it. TAKE NOTE FROM FIREPLACE takes the note through a different action and leaves the countdown running. Note that typing BURNING NOTE is read as BURNT (the dictionary shares BURN), so the note must be called BURN NOTE until it is singed.
DF7E DEFB $88,$00 Action record header: flags $88; bit 7: checks only; byte 1 $00 - checks-only: the script follows
