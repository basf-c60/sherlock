A6D3: Code $0A: one of the next n elements, at random
The byte after the code is n; a random number from 1 to n (D2A4 on n - 1, plus 1) picks which of the following n elements is printed (A5CD), the others being skipped (A6BB). The count and the choice are kept at A6D1 and $A6D2.
Input
IX The position of the code (the byte after it is n)
Output
IX At the end of the n elements
A 0
F Z

A6DB DEC A Subtract one from A

A6E5 LD A,($A6D2) Read $A6D2 in "Code $0A: the count, then the choice" into A - Is this the chosen element?

A6EB CP (HL) Compare A with the byte at "Code $0A: the count, then the choice" (A6D1)
A6EC JR NZ,$A6F5 If A differs from the byte at "Code $0A: the count, then the choice" (A6D1), skip ahead to A6F5

A6FC JR NZ,$A6E5 If the byte at "Code $0A: the count, then the choice" (A6D1) is not zero, go back to A6E5
