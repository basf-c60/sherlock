B2DF: Choose the indirect object: the candidate that passes the record's checks
Restarts the indirect-object search (B36B) and tries each candidate (B568) with the record's checks (C929), counting those that pass in $B171 and keeping the last in B185; stops at the first unless $B190 is set. $A035 is left holding the one chosen.
Output
$A035 The first indirect object that passes the record's checks
$B171 How many pass
