7DC1: Message: "FLICKERING GAS LAMPS PROVIDE ENOUGH LIGHT TO CAST SHADOWS."
Text: "FLICKERING GAS LAMPS PROVIDE ENOUGH LIGHT TO CAST SHADOWS."
No instruction loads it. It is jumped into by control code $02 at $7DF2. It is the night-time half of the hansom cab description (7DE1): after "...IN A HANSOM CAB," control code $17 (A6AC) asks C00C whether it is night; if so the next element, the $02 jump, runs and lands here, otherwise the jump is skipped and the daytime sentence about the sun follows.
