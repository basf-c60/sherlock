C821: Can the current actor ($A036) see thing A?
Addresses named in the title: $A036.
NZ if it can. Yes when the thing is what the actor is in or on (the root of the actor's own containment chain, C863); no when the thing's +5 bit 7 is clear (the underground trains, objects 37-41); yes when the thing's chain ends at the actor (carried, or in something open the actor carries) or at the same holder as the actor's; and when neither is held by anything, yes if the actor's room (A00A, set by CC29) is one of the thing's rooms (+0 is how many, from +15 on).
During one WAIT at the start, CC64 asks it about the player (thing 0) for every actor, and it answers yes only for Watson (actor 3, room 8) and the player himself, both in the sitting room; Mrs Hudson (actor 2, room 10) and everyone else get no.
Resolves the id in A via D237 and the current id in $A036 via C863 (the containment-chain walker above), and compares them - essentially 'does this candidate's ultimate container match the thing in $A036 (usually the player, or the room being checked)'.
How it works:
1. The thing is seen if it is what the actor is in or on, or the actor's own container.
2. A thing with +5 bit 7 clear cannot be seen.
3. Things held by the actor, or with the same top-level holder, can be seen; things with different holders cannot.
4. If neither is held, the thing can be seen when it is in the actor's room.
Input
A A thing number
Output
F NZ if the actor ($A036) can see it; Z if not
