F514: Move attribute address HL up a row (not past the top)
F525 down, F536 left, F540 right: the four moves of a colour run (bit 5 commands in F3C2).
How it works:
1. Each of the four entry points moves HL, the address of an attribute byte, one cell: F514 up a row, F525 down a row, F536 left and F540 right.
2. A row is 32 bytes. After the move the high byte is checked against the edges of the attribute area ($5800 to $59FF): if the move left it, it is undone, so the address never leaves the screen.
Input
HL An attribute address
Output
HL The address one cell on, or unchanged at the edge
AF is preserved
