D9C5: Tokenizer: read and classify the next word from input
Abbreviations; but EXAMINE LA finds the LABEL and EXAMINE L, TA LAMP and T LAMP give 'WHAT ?', while words with letters added (EXAMINATION, EXAMINEXYZ) are not recognised. So a typed word is matched as the start of a dictionary word (DA7D counts the letters that agree, keeping the best in $DC14; the typed length is DC13), the first word under its letter winning a tie.
How it works:
1. Skip spaces and remember where the word starts ($A029).
2. A carriage return gives an end-of-line token ($C0).
3. Characters that are not letters (the pound sign, digits, full stop, comma, quote) are read as their own tokens (DAC6).
4. Otherwise look up the dictionary words under the first letter (DA34), spell each one out (A94D) and compare it with the typed word (DA7D), keeping the best match.
5. A word that matches returns its class and word reference; no match gives a $D0 token.
Input
HL The typed line
Output
A, D The token class ($C0 end of line, $D0 not understood, $F0 number, and so on)
BC The token's value
HL Past the word
$A029 Where the word started
