C628: Check the direct object against the action record's requirement
The low nibble of an action record's byte 0 is a requirement code for the direct object, copied to $A00F by C571; the low nibble of byte 1 is the same for the indirect object (C6BE). Returns Z to refuse (C632 is JP DC15). Codes 7-15 are handed to C7A6.
0: none. 1 and 2: the object must be a room whose record (D224, the room table at 840B) has bit 7 of byte 0 set; 1 also needs D471 to find something. 3: D471 must find something. 4 and 7: anything. 5: a number ($A034 = $FE) with bit 7 of the value clear (WAIT UNTIL); 6: the same with bit 7 set (PAY TO). 8: the object must be here (C821). 9: TAKE - here, in exactly one location (C8A7), not a person (C8BE), small enough for the actor to carry (C8C6), and not held by a person (C8AF). 10: here and held by the actor. 11: here and in more than one location - a door or passage. 12: a person, with no visibility check (FOLLOW). 13-15: here and a person.
TAKE PLAIN DOOR, TAKE WATSON, GO THROUGH PLAIN DOOR and TAKE DISGUISE get 'I SEE NO ... THAT YOU CAN ...'; DROP LAMP when not carried, TALK TO LAMP, GO THROUGH LAMP, FOLLOW LAMP, GIVE LAMP TO WATSON when not carried and a second TAKE LAMP get 'YOU CANNOT ... THE ...'; PAY 5 TO WATSON gets 'DON'T BE SILLY.'
Input
IY The action record
Output
F NZ if the direct object meets the record's requirement; otherwise the command is refused through $DC15
