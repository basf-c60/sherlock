DA34: Look up this word's first letter in the dictionary index
Takes the current word's first character directly from the input buffer, masks it to 5 bits (giving 1-26 for any letter without needing a separate packing step - 'A' is $41, whose low 5 bits are 1; 'Z' is $5A, whose low 5 bits are 26), and uses that to index a 26-entry table at 5D80 of 16-bit offsets, relative to a second base at $5DBF, to find the first candidate word stored under that letter.
How it works:
1. The first letter (A = 1 to Z = 26) indexes the table of offsets at 5D80.
2. DE is where that letter's words start in the dictionary. The next letter that has words marks where they end (DA32).
3. Return Z if there are no words under the letter.
Input
HL The word
Output
DE The first dictionary record for the letter
$DA32 Where its words end
F Z if there are none
