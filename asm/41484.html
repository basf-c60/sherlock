A20C: Join free block IX to the next one if they touch
Used by A1C7. NZ if there is no next free block; Z after joining (sizes added, link taken over).
How it works:
1. Work out the address just past this free block: its start plus the size held in its first two bytes.
2. Read the link to the next free block. If there is none, return NZ.
3. If the next free block does not start at exactly that address, return NZ: there is a gap between them.
4. Otherwise add the next block's size to this one's and take over the next block's link, which unhooks it from the list, and return Z.
Input
IX The link field of a free block (its size is the word before it)
Output
F Z if the next free block was joined on, NZ if not
