C583: Pick one of the 13 numbered action records
A = a record number with bit 7 set (a verb of 128 or more, from a DO in a plan script). Looks the record up in the table at 9FAB, then copies the low nibble of its byte 0 to $A00F and of its byte 1 to $A010 (via C571 and C57A), and clears $A00B.
CB41 is taken to be the "return Z" stub; the guessing loops only try candidates until the record runs, as the helpers at C463/C60D/C613 describe.
How it works:
1. The record number (bit 7 dropped) indexes the 13 record addresses at 9FAB.
2. Set both requirement codes from the record's header (C571, C57A).
3. If the record takes no objects, run it at once (C5F4). If the direct object must be a number, $A034 must be $FE or the command is refused.
4.
Input
A A record number with bit 7 set
Output
F Z if refused; NZ if the record ran
