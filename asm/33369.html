8259: Verb patterns: the verb number is the position in this table
54 eight-byte records, one per verb phrase the parser accepts, ended by $0000. Bytes 0-5 are up to three word slots: the low 12 bits are a dictionary offset (see the dictionary at 5DC0), the high 4 bits are flags (see below). Bytes 6-7 are a fourth word slot, laid out the same way: GO for the ten directions (so GO NORTH works), CLOSELY for verb 20 (EXAMINE CLOSELY) and FURIOUSLY for verb 30 (GO FURIOUSLY TO); the narrator prints this word first ('Furiously go to the old mill road'). The high nibbles of the four slots are the record's flags, gathered by A2BD into $A01D/$A01E.
The verb number is not stored anywhere: B1AB computes it from which record the parser matched, as (record - 8259) / 8 + 1, and stores it in $A033. DOWN=10, CARRY=11, CLOSE=14, DROP=16, ENTER=18, EXAMINE=19, FOLLOW=21, GET=23, GIVE TO=26, HAIL=31, INVENTORY=33, LOOK=34, SIT IN=40, TAKE=41, TELL=47, WAIT=49, WEAR=51, KILL=52, LOCK=53, UNLOCK=54).
GO NORTH works like NORTH, and EXAMINE CLOSELY LAMP is narrated 'You closely examine the oil lamp.' - the fourth word first - and takes five minutes; EXAMINE LAMP CAREFULLY (the adverb after the object) gets 'WHAT ?'.
The flag nibbles, as far as the code and the 54 records show. A2BD packs the first two slots' nibbles into $A01D and the last two into $A01E. $A01D bit 3 (first word, nibble bit 3): the verb takes a direct object - set for every transitive verb and for none of the directions, LOOK, INVENTORY, HELLO or WAIT HERE; the narrator prints a direct object only then (A3A5), and it is also bit 7 of the first word's reference, which is what B39C/$A01C copy, so ALL can only be used with such verbs. $A01D bit 2: the verb takes an indirect object - DROP IN, GIVE TO, PAY TO, PUT IN, PUT ON, TAKE FROM, TAKE OUT OF, TAKE TO, TELL, TELL ABOUT (A3E9). $A01D bit 5 (second word, nibble bit 1): the phrase's second word goes before the direct object - CLIMB INTO, GET OUT OF, GO TO, LOOK THROUGH, SIT IN, TALK TO, WAIT UNTIL and others (A3A9). $A01E bit 7 (fourth word, nibble bit 3, only CLIMB OUT OF and GET OUT OF): one more word before the object in the narration (A3AE). $A01D bit 0: the object need not be here - FOLLOW, COME WITH, the GO TOs, HAIL, TAKE OFF, TAKE TO, TELL - copied to $A038, which lets the thing search D36A skip its is-it-here test (B4DA, B581). $A01D bit 4: no 'You ...' narration at all (A326 jumps over it) - LOOK, INVENTORY, HELLO, ENTER, FOLLOW, COME WITH, GO INTO, the GO TOs, TAKE TO, TELL and WAIT UNTIL, whose own code says what happens. $A01E bits 2-3 both set (third word's nibble 12 or 13: WAIT UNTIL, PAY TO): the direct object is a number, requirement code 5 rather than 7 (C4A1); $A01E bits 0-1 both set do the same for the indirect object (C4C0), though no verb sets them. $A01E bit 4 (HAIL, CLIMB INTO): try every candidate for the second object rather than the first that fits ($B190, B2DF), and no ALL. $A01E bit 5 (GIVE TO, PAY TO): with no preposition typed, the second noun phrase is the direct object (B421) - so GIVE WATSON LAMP gives the lamp to Watson.
The indirect object is the same with bit 2, bit 6 and $A01E bits 0-1. So bit 7 (ENTER, GO INTO, the GO TOs) and bit 6 (TAKE TO) make that object's requirement code 4 - the code C6BE treats after the room codes - instead of an ordinary thing (7). Only bit 6 of $A01E is still unread.
