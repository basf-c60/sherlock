A0F7: Move IX to the next node of a list
Every engine list links its nodes through the 2 bytes in front of each node (IX-2/IX-1). Z at the end of the list.
Input
IX A node of a list
Output
IX The next node
F Z at the end of the list (A = 0)
A0F7 PUSH HL Save HL on the stack - HL = IX's link (IX-2), the next node; A = 0 and Z at the end of the list
A0F8 LD L,(IX-$02) Read byte -2 of the record at IX into L
A0FB LD H,(IX-$01) Read byte -1 of the record at IX into H
A0FE LD A,L Copy L into A
A0FF OR H Set in A the bits that are set in H
A100 EX (SP),HL Swap HL with the word on top of the stack - IX = the next node
A101 POP IX Restore IX from the stack
A103 RET Return to the caller
