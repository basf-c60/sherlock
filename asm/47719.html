BA67: Watson's reply to something the player says
Parses the remark into a statement (BD7E: subject $BA19, relation $BA1A from the verb's place in 994D, object BA1B), then looks for it in Watson's own list at 9A7D (empty: $FF at once) and in the case table (BD51). A statement about the case is remembered: added to the list at $9FF4 (5-byte heap nodes holding the three bytes) unless already there. Watson then answers 'THAT IS BRILLIANT HOLMES.' (6F54) or, by chance, asks whether there is 'SOME CONNECTION BETWEEN THE ... AND ...' two things (6F62, using BD06); a statement with flags bit 5 set (the four 'Tricia Fender / Phipps KILLED ...' ones) gets a different answer.
SAY TO WATSON "MRS BROWN KILLED HERSELF" at the start gets a reply and the list at $9FF4 gains a node 5E 05 60 (Mrs Brown / KILLED / herself); "PHIPPS HAS PLANS" gets a reply and a node 06 03 61. "' and 'Watson says " That is brilliant Holmes. "THE LAMP IS ON", which is not about the case, gets 'Watson says " What "'; "THE LAMP IS OPEN" gets no reply at all.
