C1FC: Echo a typed character in the command window
Letters are shown in capitals (C240); ENTER becomes a space and a new line, DELETE steps back 7 pixels (C249, C267); at the end of a line the window scrolls (C271).
How it works:
1. ENTER prints a space over the cursor and starts a new line; DELETE rubs the last character out (C249).
2. Anything else is shown in capitals (C240) and printed (C388).
3. When the line is full, or after ENTER, the window scrolls up (C271) and 36 characters are available again.
4. Save the characters left, pixel shift and print position. Draw a '+' cursor after the character.
Input
A The character typed (ENTER $0D, DELETE $08, anything else)
Output
All registers kept
The character shown in the command window
