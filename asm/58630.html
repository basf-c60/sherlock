E506: Sub-script: pay the cab fare
If E518 allows it, PAY TO (E370) with the plan's objects; run by the cab sub-script at EBA4 (EBCB).
Entry points: E508 = body of record E506.
Each sub-block is one instruction. Room and object numbers are as the game uses them (the reference pages list both).
In an instruction, 'plan dobj' and 'plan iobj' are not fixed objects: they mean the direct and indirect object currently held in the actor's plan registers (bytes +4 and +5 of its actor record), so the same step works on whatever the actor is dealing with - for the player, the objects of the command just typed. 'plan verb' is the verb register (+3), 'self' is the acting character, and '-' means none.
E506 DEFB $AD,$0D Action record header: flags $AD; bit 5: test D078 first; bit 7: checks only; byte 1 $0D - checks-only: the script follows
E508 DEFB $C7,$18,$E5,$FD,$FC,$10,$E5 RUN E518 (plan dobj, plan iobj) [busy; ok E510]
E50F DEFB $0A RETURN FAIL
E510 DEFB $57,$70,$E3,$FD,$FC,$0F,$E5 RUN E370 (plan dobj, plan iobj) [busy; fail E50F]
E517 DEFB $0B RETURN OK
