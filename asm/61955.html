F203: Verb 133 (scripts only): clear bit 0 of a thing's +5 flags
Bit 0 is 'locked' (see C471), so this unlocks it.
Used by: internal verb 133 (clear bit 0 of the direct object's +5 flags).
Input
$A013 The thing's record
Output
F NZ; the thing unlocked
F203 DEFB $07,$00 Action record header: flags $07; byte 1 $00
F205 LD IX,($A013) The thing
F209 RES 0,(IX+$05) Clear bit 0 (unlock)
F20D OR $01 Make A non-zero, which clears the zero flag, and hand that back to the caller - Done
F20F RET Return to the caller
