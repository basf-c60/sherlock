E2C7: Shared HAIL action ($AA71 entry #11)
Addresses named in the title: AA71.
The player's INVENTORY/WAIT/STAND UP never reach it. It is reached through object action lists that map HAIL (and, for the same object, GET) to shared action 11 - see 8F06.
Record header: flags $47 (bit 6: pre-check routine at E298), byte 1 $10; body at E2CB. The body remembers the player's room (A00A) and the hailed cab's id + 1 (the cabbie) in E2C6, calls DD0E to move the cab into the player's room, then calls E2EE to start the cabbie on the script at F2B6 with the hailer and the cab as objects. HAIL CAB in Baker Street prints 'You hail the hansom cab.', the cabbie says 'Hello guv'nor.' and the next LOOK shows the cab with the cabbie in the street.
Input
$A034 The cab hailed
Output
F NZ; the cab moved to the player and the cabbie started on its fare script
