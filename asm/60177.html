EB11: Script helper: is THE SALE LOCATION IS OLD MILL ROAD proven?
Succeeds when bit 1 of the statement's flags ($99AC) is set; EB19 is the same for PHIPPS HAS PLANS ($999A). Lestrade's script uses them at EA2C/EA31 to decide to set off for Old Mill Road (EA5B).
Used by: RUN at EA31; RUN at EA43.
Output
F NZ if the statement at $99A9 is proven; Z if not
HL 0
EB11 DEFB $00,$00 Action record header: flags $00; byte 1 $00
EB13 LD IX,$99A9 Point IX at 99A9 in "The case: statements about the crime, and..."
EB17 JR $EB1F Skip ahead to EB1F
