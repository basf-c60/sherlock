A55D: Routines for the message control codes $00-$1F
One address per control code, used by A621. Codes below $1D are called and the interpreter carries on; $1D-$1F are jumped to instead (A62F).
What the handlers do, from reading them: $00 print the thing whose address is the next parameter; $01 print the next parameter as a word; $05 print the case statement at the next parameter; $06 name the current actor; $07 name the direct object; $08 print the character in A; $09 name the indirect object; $0A pick one of the next n elements at random; $0B print a message at an offset from here; $0C YOUR for the player, HIS for anyone else (the actor); $0D print the character in A; $0E YOUR for the player, HIS for anyone else (the direct object); $0F only in part of the day 5; $10 name the actor with the verb form (ARE / IS); $11 name the direct object with the verb form; $13 name the person in the next parameter with the verb form; $14 only in part of the day 4; $15 only in part of the day 3; $16 only in part of the day 2; $17 only in part of the day 1; $18 narrate the remembered command; $19 print the message at the next parameter; $1D end the message, no full stop, with a newline; $1E end the message with a full stop and a newline; $1F does nothing.
