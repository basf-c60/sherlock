A064: The main loop: one minute of game time per pass
Each pass is one minute. The clock moves on (BFD9) and is printed (BF79); then every actor in the table at 9860 whose next-turn time (+6/+7) has come takes its turn. A turn starts with CC37 (find the actor, check for orders or remarks waiting for it) and then runs plan-script steps (CC78) until one takes time ($A01F non-zero); that many minutes are added to the actor's next-turn time, and the actor's own after-turn routine, if it has one, runs (9C77). The player is an actor like the rest: the player's script step is the one that waits for a typed command.
Before the walk, if the player is in the middle of WAIT UNTIL (plan verb 50) and ENTER is pressed, the player's next-turn time is pulled back to now, so a long wait can be cut short.
The player's +6/+7 equals the minute counter (9FDD) whenever the game waits for a command, and moves on by 5 for WAIT and by 1 for TAKE LAMP or EXAMINE LAMP; Watson's and Lestrade's move on in step. The per-actor call counts in the B91F note (CC37 once per actor per turn) agree.
How it works:
1. Clear the ending flag $A0DA. If it is set on a later pass, go to the ending code at A0E7.
2. Move the clock on one minute (BFD9) and print it (BF79).
3. If the player is waiting until a time (plan verb 50) and ENTER is held down, make the player's next turn now.
4. Walk the actor table from 9860 in 8-byte steps until the $FF marker. For each actor whose time has come (A0DB): start its turn (CC37), then run plan steps (CC78) until one takes time ($A01F non-zero).
5. Add that time to the actor's next-turn time and run the actor's after-turn routine (9C77).
6. At the end of the table, loop for the next minute. When the ending flag is 2 the game is saved (B0E4) and the loop continues; otherwise it is loaded (B0D7) and the game restarts at A040.
