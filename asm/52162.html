CBC2: Print message DE about thing A, if it is in the player's room
Does nothing for $FF or 0, or when the thing is somewhere else. Otherwise switches output on ($5C3C = 1) and prints DE with the thing as its subject.
How it works:
1. Do nothing if the thing is $FF or 0 (nobody).
2. Find which room the thing is in (D495). If it is not the room the player is looking at ($A009), do nothing.
3. Otherwise switch printing on and climb from the thing to whatever holds it at the top, a cab for example, so that the message is about the outermost holder.
4. Make the player the current actor for a moment and ask whether the player can see that holder (C821). If not, return without printing.
5. If so, put the real actor back and print message DE with the holder's name as its subject (A59F).
Input
A The thing
DE The message
Output
Nothing is printed unless the player can see the thing
