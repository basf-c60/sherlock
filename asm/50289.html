C471: Words for a +5 flag that should be set but is not
Dictionary word references, one per bit of an object's +5 flags, printed by CB7B after 'THE <object> IS'. 0 = no word. Together the two tables name the flags: bit 0 locked, bit 2 full, bit 4 on (lit), bit 5 open, bit 6 alive; bit 7 is 'revealed' (9C56).
C471 DEFW $0930 Bit 0: UNLOCKED
C473 DEFW $0000 Bit 1: none
C475 DEFW $0288 Bit 2: EMPTY
C477 DEFW $0000 Bit 3: none
C479 DEFW $05EF Bit 4: OFF
C47B DEFW $01BB Bit 5: CLOSED
C47D DEFW $0225 Bit 6: DEAD
C47F DEFW $0000 Bit 7: none
