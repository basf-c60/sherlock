B4C1: The next candidate for the direct object ($A034)
Addresses named in the title: $A034.
Requirement code 5 ($A00F) means a number: the first time, if the slot holds one (bit 7 of $B173), $A034 = $FE and the number goes to $A02F. Otherwise searches rooms (codes below 5, D39B) or things (D36A) for the next one the slot's words name, continuing from $B17E. A = $FF when there are no more.
How it works:
1. If the requirement code ($A00F) is 5, the candidate is a number: use it once (B4A3).
2. If the slot's first word has bit 7 set, there is nothing to search: return $FF.
3. Otherwise search the rooms (D39B, for codes below 5) or the things (D36A) from the saved position ($B17E), skipping those the BUT list rejects (B517), and save the new position.
