C37D: Swap DE and HL, then move HL down a character row
Adds 32 to L, and 8 to H when that carries - the next character row, crossing into the next third of the screen when it has to. Because it swaps first, C316 calls it twice to move both of its pointers on and leave them the right way round.
Input
DE, HL Two screen addresses
Output
HL The other pointer moved down one character row
DE The pointer that was HL
C37D EX DE,HL Work on the other pointer
C37E LD A,L Copy L into A - Down a character row
C37F ADD A,$20 Add $20 to A
C381 LD L,A Copy A into L
C382 RET NC Still in the same third
C383 LD A,H Copy H into A - Into the next third
C384 ADD A,$08 Add $08 to A
C386 LD H,A Copy A into H
C387 RET Return to the caller
