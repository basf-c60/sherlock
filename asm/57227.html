DF8B: Action record: singe the note when it is picked up (RUN at $DF85)
Addresses named in the title: DF85.
The tail of the shared TAKE script at DF7E. If the burning note's countdown (9CA1) is still running it is set to $FF (stopped) and the note's name word is changed from BURNING ($0157) to SINGED ($07D5), so the TAKEn note is a singed note you can examine.
