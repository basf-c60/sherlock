A37D: Print the rest of a narrated command: verb words, objects, numbers
Part of A2E4. From the verb pattern (A2B1/A2BD) and the parse flags ($A01D/$A01E) prints the verb's words (A880), then the direct object - as a number or money (A419) when it is one ($FE), as ME when it is the actor, or by name (A745) - then any preposition and the indirect object the same way, and a full stop.
How it works:
1. Look up the remembered command's verb record and flags (A2B1, A2BD, C493, C4B2).
2. Print the verb's words: the pair at +6 of the record, then the pair at +0 (A880).
3. If the verb takes a direct object (flags bit 3): print any word that goes before it, then the object itself - a number or sum of money (A419) if it is one, ME if it is the actor, or its name (A745).
4. If there is an indirect object and the flags allow one: print its preposition, then the object the same three ways.
5. End with a full stop. The result is a sentence such as 'You pay 2/6 to Watson.'
