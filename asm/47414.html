B936: Deal with an order or remark addressed to the current actor
Called from CCB3, instead of the actor's script step, when B91F found something for it. A node with +7 = 2 goes to BA20 (Watson's and Lestrade's replies, BA67 and BB67). A node from a plan script's ASK (+1 = $FF) is handled at B98C: its verb and objects become the command, the node is removed, and the caller carries the command out (C4D1). Otherwise the words the player said are parsed for this actor (B191).
How it works:
1. Find the node waiting for this actor (B90E). If its +7 is 2 it is a remark: give Watson's or Lestrade's reply (BA20).
2. If its +1 is $FF it came from a plan script's ASK: turn it into a command (B98C).
3. Otherwise it is words the player said: restore the ALL flag and search position from the node, and parse the current sentence for this actor (B191).
4. If parsing fails, drop the sentences one by one and return Z. Otherwise keep the ALL position, drop the sentence unless it is an ALL, and return with the command to run.
