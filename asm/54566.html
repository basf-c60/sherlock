D526: List the things in place A, then what each of them holds
Names each listable thing (D57D) with commas and a final AND (D3D9, A414), marking each as seen (+6 bit 7); then, for each that has things of its own to list (D4CC), says how they are held (D590) and lists those too (calling itself). Watson is carrying the daily chronicle.'
How it works:
1. First pass: name each listable thing in the place (D57D), marking it as seen (+6 bit 7).
2. After each name put a comma, but AND before the last two and a full stop after the last.
3. Second pass: for each thing that holds others, say how it holds them (D590) and list what it holds in the same way, going down the levels.
Input
A A place
C The number of things to name
Output
The things named with commas and AND, each marked seen (+6 bit 7)
