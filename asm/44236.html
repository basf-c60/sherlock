ACCC: Note where this sentence started, so it can be read again
Skips commas ($A0), then keeps the token position ($A029, also in $A02B), E, IY and A012 at AAA1-$AAA6; when A01A is 2 it marks the node with bit 6 of +1.
Input
E Flags
IY The sentence node
Output
The start of the sentence saved at $AAA1 to $AAA6
