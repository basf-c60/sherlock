A679: Code $02: jump within the message
IX moves on by the two-byte offset that follows, less one.
Input
IX The position of the code
Output
IX Moved on by the offset
A679 LD E,(IX+$01) Read byte +1 of the record at IX into E - DE = the word at IX+1/+2 (a length)
A67C LD D,(IX+$02) Read byte +2 of the record at IX into D
A67F DEC DE Step DE back one byte - IX moves on by that length less one
A680 ADD IX,DE Add DE to IX
