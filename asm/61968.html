F210: Verb 132 (scripts only): set bit 0 of a thing's +5 flags
Bit 0 is 'locked' (see C471), so this locks it.
Used by: internal verb 132 (set bit 0 of the direct object's +5 flags).
Input
$A013 The thing's record
Output
F NZ; the thing locked
F210 DEFB $07,$00 Action record header: flags $07; byte 1 $00
F212 LD IX,($A013) The thing
F216 SET 0,(IX+$05) Set bit 0 (lock)
F21A OR $01 Make A non-zero, which clears the zero flag, and hand that back to the caller - Done
F21C RET Return to the caller
