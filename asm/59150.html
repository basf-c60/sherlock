E70E: Action record: the cabbie's parting shout (RUN at $F35C)
Addresses named in the title: F35C.
The cabbie's parting shout when a passenger has gone without paying: 'The cabbie shouts " You bloody snob, watch out if we ever meet again ... "' (6C54). The record reads +3 of the actor's table record (the saved direct-object register, CFB6): if it is non-zero it prints the shout; if it is zero it sets the ROM variable $5C3C to 1 first and then prints.
