9CA2: Phipps's after-turn routine
Once thing $55 (85, the burning note) has been revealed (+5 bit 7), counts down 9CA1; when it reaches 0, the note is described as BURNT (word $015B into its +9/+10), its +$0D/+$0E are cleared, and bit 1 of +3 of the case record at 99B7 is cleared.
With the player waiting outside, the note is revealed at 10:05am, the countdown 9CA1 (15 at the start) falls once a minute and reaches 0 at 10:24am. A plain TAKE of the note runs the shared TAKE script at DF7E, which sets the countdown to $FF (stopped) and renames the note SINGE, so it can be examined and used as evidence; TAKE NOTE FROM FIREPLACE does not run that script and the note still burns away.
