A5C4: Interpret message bytes until the end of the message
IX walks the message; A5CD handles one element - a dictionary word (bit 7 set: two bytes), packed letters, a literal character or a control code (A621) - and returns Z at the end.
Only the driver loop: A5CD does the work for each element of the message (its own block, with the element types listed there). Every message the game prints goes through here.
Input
HL The message
Output
F From the last element
A5C4 PUSH HL Save HL on the stack - IX = the message at HL
A5C5 POP IX Restore IX from the stack
A5C7 CALL $A5CD Call the routine "Interpret one message element at IX" (A5CD) - Run the interpreter one step at a time (A5CD) until it says stop
A5CA JR NZ,$A5C7 If the zero flag is clear, go back to A5C7
A5CC RET Return to the caller
