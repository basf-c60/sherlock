DDB4: Action record: default for verb 49 (WAIT HERE)
WAIT HERE: byte 1 is $50, and the player's WAIT moves the clock on by five minutes. Body and pre-check are the same three instructions at DDB8: refuse if the actor is busy (CBA7), otherwise succeed. The record at DDBE (wait a given number of minutes) uses this code as its pre-check as well.
Output
F NZ
DDB4 DEFB $40,$50,$B8,$DD Action record header: flags $40; bit 6: pre-check at DDB8; byte 1 $50
DDB8 CALL $CBA7 Call the routine "Refuse if the character is busy: 'SORRY, I CANNOT DO..." (CBA7) - (Next record's pre-check) only if the actor is not busy (CBA7)
DDBB OR $01 Make A non-zero, which clears the zero flag, and hand that back to the caller
DDBD RET Return to the caller
