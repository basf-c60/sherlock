D206: Step to the next 3-byte entry
Moves IX on 3 bytes (one exit) and tests for the $FF that ends a list. Also loads IY with the entry's bytes 1-2, which the exit walkers ignore.
Input
IX An entry
Output
IX The next entry
F Z set at the end ($FF)
