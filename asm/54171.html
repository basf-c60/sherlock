D39B: Find the next room that matches a word slot of the parse
The room counterpart of D36A: B counts on through the rooms (up to 105, then A = $FF for none), each room's record (D224) has its name words matched against the slot (A4E0), and - unless $A038 is set - only rooms that pass D471 count. Returns the room in A and IX. Its address is handed to the parser's search at $B4E9 and $B590 (LD IY,D39B), as D36A's is for things.
Input
HL A word slot of the parse
IX The search position (a room number in B)
Output

IX The search position
