A6BB: Skip one message element at IX
A word reference (bit 7) is two bytes, codes $02 and $0B are three, everything else one.
Input
IX An element of a message
Output
IX The next element
A6BB LD A,(IX+$00) Read the first byte of the record at IX into A - Skip one message element. Bit 7 set: a two-byte word reference...
A6BE BIT 7,A Test bit 7 of A
A6C0 JR NZ,$A6CC If bit 7 of A is set, skip ahead to A6CC
A6C2 CP $02 Compare A with $02 - ...codes 2 and $0B take two operand bytes (three in all)...
A6C4 JR Z,$A6CA If A equals $02, skip ahead to A6CA
A6C6 CP $0B Compare A with $0B
A6C8 JR NZ,$A6CE If A differs from $0B, skip ahead to A6CE
A6CA INC IX Step IX on to the next byte
A6CC INC IX Step IX on to the next byte
A6CE INC IX Step IX on to the next byte - ...any other code is a single byte
A6D0 RET Return to the caller
