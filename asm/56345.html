DC19: Action record: default for verb 35 (LOOK THROUGH)
LOOK THROUGH <door>: after the pre-check at DC6C, finds the exit through the door (D46C); if it leads to a room (+2), moves the actor there for a moment (DD0B), describes the room with 'YOU CAN SEE' instead of 'YOU ARE' (D0DC = 1, D1B2) and moves it back. LOOK THROUGH WINDOWS gets YOU CANNOT LOOK THROUGH THE WINDOW, LOOK THROUGH DOOR asks WHICH DOOR ?. The record's first seven bytes are header and arguments, not code.
You can see a hall.' - this is the only way found to run the body, so the door must be open.
Input
$A034 The door
Output
F NZ (done); the room beyond described as seen through the door
