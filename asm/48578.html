BDC2: Turn the player's remark into a statement
The relation is the position of the remark's verb in the list at 994D; the subject and object are the first two things named (BE3C, BE4B), each copied as a 6-byte entry into $9FF6 (people) or $9FFC (things) by BE22. Carry set if the remark names more than that.
BE22 copies thing A's 6-byte entry to $9FF6 (a person, +5 bit 6) or $9FFC; BE3C and BE4B step through the parser's object slots at $B172 and $B178.
How it works:
1. Start both searches at the top of the thing index (D04F).
2. Look the remark's verb word up in the list of relation words at 994D. Its position in that list (counting from 1) is the statement's relation. If it is not there the remark is not a statement: return Z.
3. Allow things that are not in the room to be named ($A038 = 2).
4. Find the thing that matches the subject words (BE3C). None means it is not a statement. A second match means the subject is ambiguous: return carry. Otherwise remember it and copy its six-byte entry to $9FF6 if it is a person or $9FFC if not (BE22), so that HE, IT and THEY can refer to it later.
5. Do the same for the object words (BE4B).
6. Return NZ: the statement's subject, relation and object are in $BA19, $BA1A and BA1B.
Input
$BA17 The remark's verb word
Output
F NZ if it made a statement, Z if it is not one
Carry set if a name was ambiguous
