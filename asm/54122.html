D36A: Find the next thing that matches a word slot of the parse
HL = the slot ($B172 or $B178); matches names through A4E0.
How it works:
1. Take the next thing from the index (D206); when there are none left, return $FF.
2. See whether the slot's words name it (A4E0 against its name words at +7); if not, take the next.
3. With $A038 set any match will do; otherwise it must also be visible to the actor (C821).
Input
HL A word slot of the parse
IX The last thing found
Output
A The next matching thing, $FF if none
IX Its list entry
