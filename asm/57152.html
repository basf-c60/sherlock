DF40: Action record: default for verb 19 (EXAMINE)
The pre-check (DF2E, shared with E135) refuses an object that a person other than the actor holds (C8AF). Watson holds the Daily Chronicle at the start, and EXAMINE CHRONICLE gets I SEE NO CHRONICLE THAT YOU CAN EXAMINE.
Body: sets CAAE = 1, and for the actors DC6C accepts (0, 1 and $64) prints the description (DF5B) and a newline. EXAMINE LAMP -> 'You examine the oil lamp. You see an oil lamp.' - a thing with no description message (+13/+14 empty) gets 'You see' + its name + '.'.
