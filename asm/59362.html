E7E2: Script helper: is the actor carrying this?
A record with no code to speak of (OR 1 / RET): all the work is the requirement code 10 in its header - the direct object must be here and held by the actor - so RUN E7E2 / thing simply fails unless the actor has the thing (Watson and his newspaper, Lestrade and the large rock).
Used by: RUN at E75F; RUN at E7A5; RUN at E9A0.
