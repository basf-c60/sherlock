A536: Wait for a key, but not for ever
Polls the keyboard (C41F) up to $A03B times (reset to 3,000 each call), with a 256-step delay loop between polls. A key: returns it with bit 7 cleared. No key in that time: rubs out whatever has been typed on the line (D9B7) and returns 0 with Z set.
Output
A The key pressed (0 if none)
F Z when nothing was typed in time
