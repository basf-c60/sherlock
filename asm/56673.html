DD61: Action record: find the exit to a room next door (RUN at $DD54)
Addresses named in the title: DD54.
The pre-check takes the direct object as a room number, finds the exit from the actor's room to it (D471) and refuses if there is none or if the exit is not a plain movement direction (a value below 11); the body stores that direction in plan register 9FD7. Used by the walk-to-a-room sub-script at DD52, which then DOes the direction.
Input
IX The exit found by the pre-check
Output
$9FD7 The exit's direction
