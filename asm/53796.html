D224: Find a room record
Looks the room number up in the table at 840B.
Input
A Room number
Output
IX Address of its record

D225 LD DE,$840B Point DE at the room table (840B)
D228 PUSH HL Save HL on the stack

D22F INC HL Step HL on to the next byte
D230 LD D,(HL) Read the byte HL points at into D
