A5CD: Interpret one message element at IX
Bit 7 set: a two-byte dictionary reference, printed by A887 - unless its flag nibble is $20, $30 or $60, which A647 treats as references to the command's own words (actor, objects). $00-$1F: a control code (A621). $20-$3F: that character. $40-$5F: a run of (low 5 bits + 1) letters packed 5 bits each, unpacked by A990. $60 and up: A83A.
How it works:
1. Bit 7 set: a two-byte dictionary reference. Classes $20, $30 and $60 are the sentence-ending words (A647); any other is printed (A887).
2. Codes $20 to $3F: a single literal character. $40 to $5F: a run of (code AND $1F) + 1 letters packed five bits each (A990), each printed as it is unpacked.
3. $60 and above: one of the common words (A83A).
4. Below $20: a control code, which is looked up in the handler table at A55D and called. Codes below $1D carry on; $1D and above end the message.
