C481: Words for a +5 flag that is set but should not be
Dictionary word references, one per bit of an object's +5 flags, printed by CB7B after 'THE <object> IS'. 0 = no word. Together the two tables name the flags: bit 0 locked, bit 2 full, bit 4 on (lit), bit 5 open, bit 6 alive; bit 7 is 'revealed' (9C56).
C481 DEFW $0517 Bit 0: LOCKED
C483 DEFW $0000 Bit 1: none
C485 DEFW $035F Bit 2: FULL
C487 DEFW $0000 Bit 3: none
C489 DEFW $05FF Bit 4: ON
C48B DEFW $060B Bit 5: OPEN
C48D DEFW $0000 Bit 6: none
C48F DEFW $0000 Bit 7: none
