A9B7: Print character A, a word at a time (word wrap)
Every character the message interpreter prints comes here. Unless quoted printing is on ($A027: straight to C1E1), characters are collected in the buffer at $5C0B, a backspace (8) taking the last one off again - which is how suffixes such as '<delete>IES' work. A space, a carriage return or a quote mark ends the word: if the word is longer than the count at C1F5 allows, a new line is started first, and then the word is sent to AA14 character by character. AA14 turns letters to lower case and drops spaces at the start of a line ($A025 = 0 there).
How it works:
1. If quoted printing is on ($A027), send the character straight out (C1E1).
2. A space, carriage return or quote ends a word. Any other character is added to the word buffer at $5C0B; a delete removes the last letter.
3. When a word ends: if it does not fit on the rest of the line (C1F5), start a new line first. Then print the word, and then the character that ended it.
Input
A The character to print
Output
All registers kept
