EBD5: Action record: remember which cab is meant (RUN at $EBAA, $EBBB)
Addresses named in the title: EBAA, EBBB.
Puts the direct object's number plus one into plan register 9FD6. In the cab-hailing sub-script at EBA4, which Lestrade, Phipps, the Major and the German agent each run when they take a cab, it names the cab they have just hailed.
Input
$A034 The cab
Output
$9FD6 The cab's number plus 1
F NZ
EBD5 DEFB $07,$00 Action record header: flags $07; byte 1 $00
EBD7 LD A,($A034) Read $A034 in "Game variables" into A - The direct object's number plus 1...
EBDA INC A Add one to A
EBDB LD ($9FD6),A ...goes into plan register 9FD6
EBDE OR $01 Make A non-zero, which clears the zero flag, and hand that back to the caller - Succeed
EBE0 RET Return to the caller
