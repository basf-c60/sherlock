A59F: Print the message at HL
The message interpreter's entry point; almost every word the game prints comes through here (see the message area at 67B7 for the bytecode). Parameters - extra messages or words, such as what a character says - are pushed on the stack before the call and control codes pick them up; on the way out the stack pointer is reset past them (A59D), so callers push and never pop. Saves the registers, runs the byte loop (A5C4 / A5CD) and returns through JP (HL).
How it works:
1. Save the registers and take the address of the caller's parameters (stack pointer plus 12) for A59D.
2. Clear $A00C unless $A00B is set.
3. Run the interpreter over the message (A5C4).
4. Restore the registers, drop the parameters from the stack and return.
Input
HL The message
SP+ Any parameters the caller pushed, dropped on return
Output
All registers kept
