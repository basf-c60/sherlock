A63A: Codes $08 and $0D: print the code itself
Prints A - the control code, so a backspace or a newline - through the word-wrapping printer (A9B7), and carries on (XOR A). Code $08 is A736, the same three instructions.
Input
A The code to print
Output
F Z (XOR A)
A63A CALL $A9B7 Call the routine "Print character A, a word at a time (word wrap)" (A9B7) - (Print the character in A and succeed)
A63D XOR A Set A to zero, which sets the zero flag for the caller
A63E RET Return to the caller
