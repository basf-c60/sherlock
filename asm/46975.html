B77F: Fetch the next word for $B6FD's name match
Addresses named in the title: B6FD.
Fetch the next word of a message for B6FD's name match. B77E is $FF once the last word of the message has been given out.
How it works:
1. If B77E is $FF, the message is finished: take the most recent saved call position from the list headed at B6D6 (none left: return Z), unhook it, free its node (A1C7) and carry on reading just after the call.
2. Read the next byte. If bit 7 is set it starts a two-byte dictionary reference, which is put in DE. If its class ($70 bits) is $60, $30 or $20 it is the last word of the message, so B77E is set to $FF. Return NZ with the word in DE.
3. Below $20 is a control code. Code 2 is a jump: add the 16-bit offset to the position and carry on. Code $0B is a call: make a 2-byte node holding the position after the call, put it on the front of the list at B6D6 and go to the sub-message. Codes $1D to $1F end the text. Other codes are skipped.
4. $20 to $5F is a run of packed letters, (byte AND $1F) + 1 of them at five bits each (A990); they are stepped over, not returned.
5. $60 and above is one of the common words (A840): return NZ with A = 0.
Input
IX The message position
Output
F Z when no words are left; NZ when a word was found
DE The dictionary reference when A is not 0
IX The position after the word
