CB7B: Refuse by naming the flag that failed: "THE ... IS <word>"
Takes the lowest bit in CB79 and prints 6817 ('THE <object> IS') followed by that bit's word: from C471 when a needed bit was missing, from C481 (bit 7 of CB79 set) when a forbidden bit was present. The object is $CB7A, saved by C685.
Input
$CB79 The flag bits that failed
$CB7A The object
Output
A message like "THE ... IS <word>" printed
