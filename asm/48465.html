BD51: Find the statement $BA19-$BA1B in the case table
Addresses named in the title: $BA19, BA1B.
Z with IX = the statement if found (BD69 compares subject, relation and object in that order). BD4B searches Watson's own list at 9A7D the same way.
How it works:
1. Start at the first record of the case table (9965), or - from BD4B - at Watson's own list (9A7D).
2. A first byte of $FF ends the table: return NZ.
3. Compare the record with the statement being looked for: its relation ($BA1A) with byte +1, then its subject ($BA19) with +0, then its object (BA1B) with +2. All three must match.
4. On a match return Z with IX at the record; otherwise step to the next record (BE5A), skipping any evidence records that belong to this one, and repeat.
Input
$BA19 The statement's subject
$BA1A Its relation
$BA1B Its object
Output
F Z if found, NZ if not
IX The record, if found
