D7FA: Player's turn: turn the sentence into a command (RUN at $993C)
Addresses named in the title: 993C.
Part of the player's own script (see 993C): parses the sentence at 9FF2 into a verb and objects (B191) and copies them into the plan registers (9FD6-9FD8), where the script's DO picks them up. With ALL ($A01C, kept in D6B8 between turns) the sentence is kept so that the next turn takes the next thing; otherwise its node is freed, with any BUT nodes after it. If the sentence does not parse, an ALL that has run out of things fails quietly (DC15, with $A033 = $FF); anything else sets D7E0 so that the rest of the line is thrown away (D7E1).
This record is one step of the loop in the player's own plan script at 9921: DO LOOK once, then read a line (D6BF), split it into words (D715), check there is a word (D769), parse a sentence (D77E), check there is a sentence (D7D9), turn it into a command (D7FA) and DO it. When you wear the china man's disguise the same script runs for him; the counts below include both.
How it works:
1. Carry the ALL flag over from the last turn and take the sentence at 9FF2.
2. Parse it into a verb and objects (B191). If that fails, set the failure flag and finish.
3. Put the verb and objects in the plan registers (9FD6, 9FD7), and note where the ALL search got to.
4. If ALL is still going keep the sentence; otherwise unhook and free its node.
Input
$9FF2 The sentence
Output
$9FD6 The verb
$9FD7 The objects
F Z if the sentence could not be made into a command
