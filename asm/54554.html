D51A: List the things in a place, with commas and AND
D526 does the work: it also marks each thing listed as seen by the player (+6 bit 7), which is what the case's evidence tests (see 9965).
Input
A A place
B, C As for $D526
Output
The things in the place listed; IY, DE, BC kept

D51C PUSH DE Save DE on the stack
D51D PUSH BC Save BC on the stack
