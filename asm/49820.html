C29C: Move part of the command window down a row and clear the gap
LDDR of 128 bytes - four character rows ending at $50DF - down by 32 bytes, for each of the eight pixel lines; then HL = $5060 and on into the row-clearing code of C271 (C28D). Called at C260 by the character printer when the typed line runs past the end of a screen line.
Output
Part of the command window moved down one row and the gap cleared
HL, DE, BC Kept
C29C PUSH HL Save HL on the stack - Rows 19-22 down a row, from the end backwards
C29D PUSH DE Save DE on the stack
C29E PUSH BC Save BC on the stack
C29F LD HL,$50DF Load HL with $50DF
C2A2 LD DE,$50FF Load DE with $50FF
C2A5 LD A,$08 Load A with $08 - For each of the eight pixel lines:
C2A7 PUSH HL Save HL on the stack
C2A8 PUSH DE Save DE on the stack
C2A9 LD BC,$0080 Load BC with $0080 - move four character rows (128 bytes)
C2AC LDDR Copy BC bytes from where HL points to where DE points, counting down
C2AE POP DE Restore DE from the stack
C2AF POP HL Restore HL from the stack
C2B0 INC H Add one to H - Next pixel line
C2B1 INC D Add one to D
C2B2 DEC A Subtract one from A
C2B3 JR NZ,$C2A7 If A is not zero, go back to C2A7
C2B5 LD HL,$5060 Load HL with $5060 - Then clear row 19 with C271's code
C2B8 JR $C28D Go back to C28D
