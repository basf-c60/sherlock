C9BF: Run an action record (HL = the record)
Action records are a small data format that every verb's behaviour is written in. Byte 0 is a flags byte, byte 1 holds a value whose high nibble is stored at $A01F.
The executable body starts after the header: record + 2, + 2 more if bit 6, + 5 more if bit 4. CA64 runs the body through the dispatcher at CB2C.
SIT IN's $78 header puts the body at record + 9, E413).
The clock does move by 5 for one WAIT (value 5) and 2 for GET OUT (value 2), but another WAIT moved it by 1 and SIT IN (value 2) by 1.
WAIT (WAIT HERE, byte 1 $50) moves it on by 5, TAKE LAMP (DCC1, $10) and EXAMINE LAMP (DF40, $10) by 1 each.
How it works:
1. Refuse if it is too dark (D078) and the record cares about that.
2. Check the direct object (C628) and the indirect object (C6BE) against the record.
3. If bit 6 of the record is set, run its pre-check routine; if that refuses, stop.
4. Otherwise take the high nibble of byte 1 as the action's length ($A01F) and run the body, narrating the action first and describing any change.
Input
HL An action record
Output
F Z with HL = the refusal handler if refused; NZ if the record's checks pass; carry set if it is a script
