E2EE: Start actor A on the script at DE, with objects B and C
$A034 = B and $A035 = C; with A as the current actor (CC0E) the script is pushed as its plan (CF80, B = 2) and its script position (+1/+2 of its actor-table entry) set to DE. The HAIL action (E2C7) uses it with DE = F2B6 to set the cab and cabbie off.
Input
A The actor
DE The script
B, C The two objects
Output
F NZ; the actor's old script is kept as a sub-script and the new one started

E2F8 LD A,($A036) Read $A036 in "Game variables" into A - Keep the current actor and make A the actor
