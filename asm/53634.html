D182: Print a room's description
HL = the room's own description text (+7/+8 of its record); if it has none, the opening from D0DD with the room's name (D1C6) and a full stop. D1B2 is the brief version for a room already visited, adding 'IT IS TOO DARK TO SEE MUCH ELSE.' (68C1) when dark.
Input

Output
