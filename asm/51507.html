C933: Find the action record for the current command
So a person's list holds actions it does itself, not actions done to it - Tricia Fender's (TELL ABOUT / TELL, shared 3) and Mrs Jones's (shared 22) are the only ones. Only if that fails is the direct object's list searched. SAY TO TRICIA FENDER "TELL ME ABOUT THE BLOODSTAINED CLOTHES" reaches shared action 3 (E1B4) with Tricia acting and the clothes as indirect object, while TELL TRICIA FENDER ABOUT ... (the player acting) does not.
Chooses which action record carries out the current verb ($A033). If the actor ($A017) or the direct object ($A013) has its own entry for the verb (found by D1DC), the entry's second byte is an index into the shared action table at AA71 (C960). Otherwise the verb's default record comes from 9F38 (C972); a verb with no default fails via DC15. Either way, C996 then runs the record.
How it works:
1. If the actor is a person (+5 bit 6) and lists this verb in its own actions (D1DC), look the verb up in the shared actions table (D349); a shared action that is found is run.
2. If the direct object needs to be a thing (requirement code 7 or more) and lists this verb in its own actions, use that.
3. Otherwise look the verb up in the default-action table at 9F38; with no default the command fails (DC15).
Input
$A017 The actor's record
$A033 The verb
Output
The action record chosen and run through $C996
