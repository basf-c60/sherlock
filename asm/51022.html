C74E: Test object C's +5 flags against a record's masks
B holds two 2-bit modes and L/H two masks. Mode 0: every mask bit must be set; 1: at least one (or the mask is 0); 2: none may be set; 3: not all may be set. On failure the offending bits go to CB79 (bit 7 set when a bit was present that should not be) and HL = CB7B, the refusal that names the flag.
OPEN YOUR DOOR when it is open leaves CB79 = $A0 and prints 'YOUR DOOR IS OPEN'; CLOSE YOUR DOOR when it is closed leaves $20 and prints 'YOUR DOOR IS CLOSED'. The door's +5 goes $80 -> $A0 when opened and back when closed.
Input
C An object
B Two modes (bits 2-3 for mask L, bits 0-1 for mask H)
L, H The masks
Output
F NZ if the object's +5 flags pass both tests; Z if not
