AEA9: IY = the next node in the list (Z at the end)
The link is the two bytes before the node (IY-2, IY-1), as in every heap block (A11C).
Input
IY A node
Output
IY The next node
F Z at the end of the list
AEA9 PUSH HL Save HL on the stack - As A0F7 but for IY: IY = the next node, Z at the end
AEAA LD L,(IY-$02) Read byte -2 of the record at IY into L
AEAD LD H,(IY-$01) Read byte -1 of the record at IY into H
AEB0 LD A,H Copy H into A
AEB1 OR L Set in A the bits that are set in L
AEB2 EX (SP),HL Swap HL with the word on top of the stack
AEB3 POP IY Restore IY from the stack
AEB5 RET Return to the caller
