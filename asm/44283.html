ACFB: After a sentence: copy the objects on, or rewind to read it again
In statement mode ($A024 = 2) copies the node's six bytes from +8 to +$18 and parses on (AB4C). Otherwise, unless $A01B is set, goes back to the position saved by ACCC and frees the nodes after it (A1AF).
How it works:
1. In statement mode ($A024 = 2), do this once only: copy the node's first group of six bytes (+8) to the third group (+24), so the subject can be shared, and read on for the object (AB4C).
2. In command mode, if $A01B is set (a line of sentences is being worked through), just read on.
3. Otherwise go back to the start of the sentence, whose position, flags, sentence count and node were saved by ACCC, free the nodes that were made after it (A1AF) and unhook them, ready to read the sentence again.
Input

IY The parse node
