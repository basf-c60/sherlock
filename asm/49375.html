C0DF: Load the saved-game block from tape
DE = length, IX = start (kept at C109/C10B). Prints 'PLAY SAVED GAME TAPE TO BE LOADED' (C0BC), reads the 17-byte header into C0FE with LD-BYTES until one arrives, then the block (C089).
Input
IX The start of the block
DE Its length
Output
F Carry set when the block loaded correctly
