CF80: Save a sub-script call frame
Allocates a 7-byte node on the list at 9FE9: +0 the actor, +1/+2 HL (the calling instruction), +3/+4 the command's objects ($A034/$A035), +5 B, +6 the plan's verb (9FD6). CFB6 finds the current actor's frame; CFCF returns from the sub-script, restoring the script position and freeing the frame, and gives A = frame +5.
How it works:
1. Allocate a seven-byte node from the heap (A11C).
2. Fill it in: the actor ($A036); HL, where the script should carry on after the sub-script; the command's two objects ($A034, $A035); B; and the plan's verb (9FD6).
3. Link the node in at the head of the list of call frames at 9FE9.
4. The same block has two more entry points. CFB6 finds the current actor's frame by walking the list: NZ with IX at the frame, or Z if there is none. CFCF is the return: it finds the frame, sets the actor's script position back to the calling instruction, unlinks and frees the frame (A1C7), reloads the plan registers (D008) and returns the saved byte in A.
