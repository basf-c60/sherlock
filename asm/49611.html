C1CB: Print a message: plain ASCII, last byte has bit 7 set
A short, self-contained loop: read a byte, strip bit 7, print it (via the gated entry at C1FD), then check whether the *original* byte (before stripping) had bit 7 set - if so, that was the last character of the message and the loop stops; otherwise it advances and repeats.
Input
HL A message whose last byte has bit 7 set
Output
The message printed
HL At the last byte
C1CB LD A,(HL) A = this message byte, with the terminator bit stripped
C1CC AND $7F Keep only bits 0, 1, 2, 3, 4, 5, 6 of A (mask $7F)
C1CE CALL $C1FD Print it
C1D1 BIT 7,(HL) Did the ORIGINAL byte have the terminator bit set?
C1D3 RET NZ ...then that was the last character - stop
C1D4 INC HL Else: next byte
C1D5 JR $C1CB Jump to C1CB
C1D7 RET Return to the caller
This entry point is used by the routine at A11C.
C1D8 LD HL,$13C5 Load HL with $13C5 - HL = $13C5; (C1C0); then on to A0EB
C1DB CALL $C1C0 Call the routine "Print a prompt at HL, wait for a key, newline" (C1C0)
C1DE JP $A0EB Go back to A0EB
