C542: Should the indirect object be guessed?
NZ when the action record wants an indirect object ($A010, its header byte 1's low nibble, is not 0), none was typed ($A035 = $FF) and bit 1 of $A01D is clear.
Input
$A010, $A035, $A01D
Output
F NZ when an indirect object should be guessed; Z when not
C542 LD A,($A010) Read $A010 in "Game variables" into A - No indirect object wanted ($A010 = 0): no guessing - Z

C546 RET Z If A is zero, return
