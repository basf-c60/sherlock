E57A: Script helper: tick the countdown (fail when it runs out)
Its pre-check (E573) refuses when the actor has no countdown. The body counts it down: still running, the instruction succeeds - taking no time, so the script goes straight on (scripts pair it with IDLE, E5A8, which takes a minute); at zero the countdown is removed and the instruction fails, so a script can 'do X until the time is up' with a success branch back to X.
Used by: RUN at E482; RUN at E76C; RUN at E7AC; RUN at EEB6; RUN at EF40; RUN at F010; RUN at F088; RUN at F2C6; RUN at F2E0; RUN at F317; RUN at F352.

F NZ while the countdown runs; $DC15 when it runs out and is removed
