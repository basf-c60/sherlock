C0FE: The saved game's tape header: a CODE file 'SHD V2.0'
The standard 17-byte header SA-BYTES writes first: type 3 (code), the ten-letter name 'SHD V2.0 ', then the length, start and second parameter. The length and start words are where C046/C04A and C0DF keep DE and IX between the header and the block, so they are filled in when the game is saved. A load reads a header into the same place.
C0FE DEFB $03 Type: 3 (code)
C0FF DEFM "SHD V2.0 " Name
C109 DEFW $0000 Length (DE)
C10B DEFW $0000 Start (IX)
C10D DEFW $8000 Parameter 2
