EF9C: Action record: the first messenger takes a note from Basil (RUN at $EE95)
Addresses named in the title: EE95.
Prints 'A messenger arrives at the door, takes a note from Basil and dissapears down the street.' (75E8). It is run by Phipps's script at EE95 on Tuesday at 1pm, only when you (or the china man) are in Camden Street or Basil's front yard (rooms 32 and 102).
Output
F NZ; the message printed
EF9C DEFB $00,$00 Action record header: flags $00; byte 1 $00
EF9E LD HL,$75E8 Point HL at the message text, "A messenger arrives at the door, takes a note from Basil and disappears down the street." (75E8)
This entry point is used by the routine at EFAC.
EFA1 LD A,$01 A = 1: the value the output switch needs for the message to appear on screen. (A second entry point: the sibling record at EFAC joins here with its own HL.)
EFA3 LD ($5C3C),A Store it in the output-switch byte ($5C3C), so the print routine really draws the text instead of staying silent
EFA6 CALL $A59F Print the message at HL (A59F)
EFA9 OR $01 OR $01 makes A non-zero, which clears the zero flag: the plan interpreter reads "not zero" as "the action happened"
EFAB RET Return to the plan interpreter
