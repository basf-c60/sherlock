F3C2: Draw a picture (the picture interpreter)
HL = the picture's bytecode (from the table at F60C via A277). The pen starts at (127, 63).
How it works:
1. The pen starts at (127, 63). Take the next command; 0 ends the picture.
2. $08 moves the pen to the (x, y) in the next two bytes (x always has bit 7 set, so the pen stays in the right half of the screen).
3. A command with bit 7 set draws a line (F56E): its low three bits give the direction, and the rest the number of steps and run lengths.
4. Other commands set the colour, fill an area (F490) or draw other shapes; each is followed by its operands.
Input
HL The picture's bytecode
Output
The picture drawn; registers kept
