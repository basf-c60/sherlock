D8AD: The line editor
Prints the '> ' prompt and reads up to 128 characters into $5B00 through A536: DELETE rubs out (and keeps track of quote marks, D897), $18 clears the line (D9B7), letters, digits and a few punctuation marks are accepted, ENTER ends the line (D949). A time-out from A536 ends it with nothing (D9AC).
How it works:
1. Print the prompt '> ' and set up the buffer at $5B00; B counts down from 128, with bit 7 set while nothing has been typed.
2. Wait for a key with the time limit (A536). If time runs out, give up: the player will wait.
3. On an empty line, '@' repeats the last command (D99E). The first key of a line may be a cursor key, which is turned into a one-key move (D978).
4. Rub-out ($18) clears the whole line; DELETE removes one character, and removing a quote mark flips the inside-quotes flag.
5. Letters are taken. A quote mark flips the flag (closing a quotation first ends it with a full stop). Space, full stop, comma, slash, the pound sign, hyphen, colon and digits are taken. Anything else is ignored.
6. ENTER closes any open quotation, ends the line with a full stop (D968) and a carriage return, and returns NZ.
