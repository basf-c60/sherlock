AB91: Read a sentence's verb words into the node at IY
Tokens (AE7F) of class $30 (a verb, see AE7F) go to IY+0/+1, class $00 to IY+2/+3, $40 and $20 to one or the other by the flags in E; $E0 tokens are skipped; anything else ends the verb (carry when a slot was wanted twice). In statement mode ($A024 = 2, while a case statement is being said) the verb must instead be one of the eleven relation words at 994D - KILLED, HAD, ... - and NZ means it is not.
How it works:
1. In statement mode ($A024 = 2) the words are matched against the relation words at 994D instead (ABF3).
2. Otherwise take tokens (AE7F). A class $30 token goes in the verb slot (IY+0/+1), a class $00 token in the second word slot (IY+2/+3).
3. A class $40 token clears E bit 0 and is treated as a verb; a class $20 token goes to whichever slot is free.
4. A word for a slot already taken returns carry set. Any other class ends the verb: return Z if the verb slot has been filled.
Input
IY The sentence node
E Slot flags (bit 0, 1, 2)
Output
F Z if the verb slot was filled; NZ if not; carry set for a second word in a slot already taken
E Updated
