B39D: Look the typed verb up in the verb table ($8259)
Addresses named in the title: 8259.
Takes the verb's two word references from IY (bit 7 of the first kept in B39C), clears and fills a match pattern at $B186-B18D (B483), then walks the 8-byte verb records from 8259 comparing each (A4CD) until one matches - then B405 and NZ - or the zero record that ends the table (Z).
How it works:
1. Take the verb's word reference from the parse node. Bit 7 of it says ALL was typed with the verb; keep that in B39C and clear it.
2. Build the pattern to match at $B186-B18D: the verb word, the particle at node +2 (CLOSELY, FURIOUSLY, a direction), and up to two more words from the node's other slots (B483).
3. Walk the eight-byte verb records from 8259, comparing each with the pattern (A4CD).
4. On a match, fill the object slots (B405) and return NZ. If the zero record that ends the table is reached, return Z.
Input
IY The parse node
Output
F NZ if a verb record matched, Z if none did
