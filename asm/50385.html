C4D1: Carry out the command in $A033-$A035 for the current actor
Addresses named in the title: $A033, $A035.
Verbs 128 and up go to C583 (the script-only verbs). Then C929 finds and runs the action record.
How it works:
1. A verb number with bit 7 set is a script-only verb: use the numbered record (C583).
2. Otherwise find the verb's pattern record (A2B1), gather its flags (A2BD), and set the two objects' requirement codes (C493, C4B2).
3. If a number is required, the object must be $FE. If a required direct object is still $FF, ask for it.
4.
Input
$A033 The verb
A034 The direct object, A035 the indirect object
$A036 The actor
Output
F Z if refused; NZ if the action was done
