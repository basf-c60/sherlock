D715: Player's turn: split the typed line into words (RUN at $9928)
Addresses named in the title: 9928.
The player's turn starts here: the page line count ($A019) is cleared and the text lines go back to full width (C142). Then, unless '@' asked for the last command again (D714), the typed line at $5B00 is run through the tokenizer (D9C5) word by word into the list at $5B81: one class byte per token, followed by its two-byte value for words of class $E0, $F0 or $90 and for anything below $80; the list ends at class $C0. D6BD is pointed at the list and the record succeeds.
This record is one step of the loop in the player's own plan script at 9921: DO LOOK once, then read a line (D6BF), split it into words (D715), check there is a word (D769), parse a sentence (D77E), check there is a sentence (D7D9), turn it into a command (D7FA) and DO it. When you wear the china man's disguise the same script runs for him; the counts below include both.
How it works:
1. Clear the page line count and put the text at full width (C142). If '@' was typed, use the last word list again.
2. Otherwise clear the 96-byte word list at $5B81 and read tokens from the typed line (D9C5).
3. Store each token's class; classes $E0, $F0, $90 and those below $80 are followed by a two-byte value.
4. Continue until the end marker.
