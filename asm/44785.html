AEF1: Merge parse node IX into node IY
ORs in IX's flag byte (bit 7 dropped) and takes its first byte; if IX has words at +4/+5 and IY's ten bytes from +$0E are empty (AF38), moves IY's six bytes from +8 up to +$12 and copies IX's words in (AF52, and AF56 for the +2 pair if IY has none).
How it works:
1. IY takes IX's verb: the low byte at +0 and the other flag bits from +1 (without bit 7).
2. If IX has no words at +4 and +5 there is nothing more to do.
3. If IY already has words at +14 to +23 stop. Otherwise move IY's first group up to the second group and copy IX's words from +4.
4. Copy IX's second word in as well if IY has none.
Input
IX The node to merge
IY The node to merge it into
Output
IY Updated
