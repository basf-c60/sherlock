DAEF: Read a time, or a number that may turn out to be money
A number followed by ':' (minutes), 'A' or 'P' (then 'M') is a time: B = the hour with bit 7 set and bit 6 for AM, C = the minutes with bit 6 for PM. Anything else goes to the money reader at DB84 (so '2/6' and '3S' need no '£'). Returns A = $F0 for a number token, or $D0 and BC = 0 if it makes no sense.
Input
HL The number
Output
A $F0 (a number) or $D0 (not understood)
B, C The time, or 0
HL Past it
