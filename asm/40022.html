9C56: Set an object's 'revealed' flag (+5 bit 7)
Finds the object (D237) and sets bit 7 of its +5 flags - the bit the flag-word tables at C471 call revealed - then returns NZ.
Input
A The thing number
Output
IX The thing's record
F NZ
9C56 CALL $D237 Thing A's record (D237)
9C59 SET 7,(IX+$05) Set bit 7 of +5 (visible)
9C5D OR $01 Make A non-zero, which clears the zero flag, and hand that back to the caller - Return NZ
9C5F RET Return to the caller
