9CE9: Say good morning to C, if just met
Used by after-turn routines: 9CF2 checks whether C is here and seen and whether the greeting countdown at HL has run out; if so the countdown is set to 30 to 45 minutes (30 plus a random number from 0 to 15) and 6929 is printed: '<actor> SAYS TO <C> "GOOD MORNING".' While C stays away the countdown runs down by one a turn, so characters greet each other again only after a while apart.
