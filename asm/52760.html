CE18: Plan opcodes 1, 2, 3 and 7: DO a command or RUN a record
CE18 (opcode 2): verb, direct and indirect object from the instruction, through CEDE, then C4D1 runs the command. CE3B (7) and CE4F (3): run the action record named in the instruction directly (C591), with or without objects. CE6A (1): a verb alone. In each case carry back from the command means a sub-script was called (the script position has already moved), Z means it failed and NZ means it succeeded.
Input
IX The instruction
Output
The command or record run; the step succeeds, fails or starts a sub-script
