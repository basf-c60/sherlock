DDBE: Script helper: wait n minutes
RUN DDBE / n: the action takes n minutes ($A01F = n), so the actor's next turn comes n minutes later. Pre-check DDB8 as for WAIT HERE.
Used by: RUN at EEBE; RUN at EEE4; RUN at EF04; RUN at EF54; RUN at EF75; RUN at F0E9; RUN at F22D; RUN at F246; RUN at F25B; RUN at F268; RUN at F278; RUN at F28D; RUN at F2AC.
Input
$A034 The number of minutes
Output
$A01F The minutes
F NZ
DDBE DEFB $40,$00,$B8,$DD Action record header: flags $40; bit 6: pre-check at DDB8; byte 1 $00
DDC2 LD A,($A034) n...
DDC5 LD ($A01F),A ...is how long this takes
