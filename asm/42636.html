A68C: Codes $0F, $14-$17: only in one part of the day
Each asks C00C what part of the day it is (1-5) and, unless it is the code's own (code $0F: 5, $14: 4, $15: 3, $16: 2, $17: 1), skips the next element of the message (A6B2, A6BB). So a message can say different things by day and by night.
Input
IX The position of the code
Output
F Z; the next element is printed only in the code's own part of the day, otherwise it is skipped
A 0 when skipped
