CC37: Start an actor's turn
On failure to resolve the id, clears $A01F and returns early instead.
How it works:
1. Clear the failure count (CC0B). Find the actor's record (CC0E); if there is none, make the action take 1 minute and stop.
2. Keep the record address (9FDB) and the actor ($A036), and note whether an order or remark is waiting (B91F).
3. Set up the actor (CC29) and note the player's room (D045).
4. Switch output on only when the player can see the actor (C821). Clear $A01F.
Input
A The actor number
Output
$A01F 0 (or 1 if the actor is not in the table)
IY The actor's record
$A036 The actor
$5C3C Output on only when the actor is seen by the player
