9E6A: Game-over record: 'I do not think you are doing too well'
Ends the game with 693A unless 9D90 is set - that is, unless the player has been introduced to Lestrade (see 9DFF). Run by Inspector Lestrade's script (E932). Perhaps you should try again.' at 2:59pm on Monday, and the game restarts.
9E74 is the shared ending: prints the message in HL, waits for a key (C306), and restarts (B0AC).
Output
F NZ and nothing printed once Lestrade has been introduced; otherwise the game ends through $9E74
9E6A DEFB $00,$00 Action record header: flags $00; byte 1 $00
9E6C LD A,($9D90) Read "Lestrade's flags" (9D90) into A
9E6F AND A Clear the carry flag for the caller (A is unchanged)
9E70 RET NZ If A is not zero, return
9E71 LD HL,$693A
