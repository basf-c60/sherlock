C2BA: Print one character (or handle a newline) at the cursor
The routine PLOT-CHAR's caller: restores the persisted cursor position/column-shift from C1F8/$C1FA, and either plots the passed-in character directly (calling PLOT-CHAR via C2EE), or, if the character is a carriage return ($0D), counts the line in $A019, waits for a key after fifteen (C306), and scrolls the window up (C316) to print the next line at the start of row 17. A character that fills the line (36 to a line, 18 beside a picture: C1F5) is followed by a newline of its own.
This, plus PLOT-CHAR and the page-wait wrapper at C306, forms the game's whole low-level text-output path: every piece of printed text - room descriptions, parser responses, dialogue - goes through here one character at a time.
How it works:
1. Pick up the text print position (C1F8) and pixel shift ($C1FA).
2. A character other than ENTER is printed (C388); if the line is then full a new line is started.
3. A new line after fifteen lines of text ($A019) waits for a key (C306) first. Scroll the text up a row (C316), and start the new line with 36 characters (18 beside a picture).
Input
A The character (or $0D for a new line)
Output
The character printed at the text cursor; registers kept
