BCC9: Try to prove statement IX
If it has evidence (flags bit 2), checks it (BF08) and fails if it is not all there. Then marks it proven (bit 1 set, bit 0 clear) and runs its routine (+4/+5) if bit 4 is set; a statement with bit 5 set is only marked as waiting (bit 0). Z = proven.
How it works:
1. If the statement has evidence (flags bit 2), check all of it (BF08). If any is missing, return NZ: not proved.
2. If flags bit 5 is set, the statement is only marked as waiting (bit 0 set) and Z is returned. It will be settled later by BC46.
3. Otherwise mark it proved (bit 1 set, bit 0 clear). If bit 4 is set, run its routine at +4/+5 (D1DB): the routines from 99FC on, which print what Lestrade or Watson says and may set a marker.
4. Return Z: proved.
Input
IX The statement record
Output
F Z if proved (or marked as waiting), NZ if the evidence is not all there
