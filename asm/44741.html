AEC5: IY = the node before IY in the sentence list ($9FF0)
Addresses named in the title: 9FF0.
Through A104, stepping back over nodes marked with bit 6 of +1 and stopping at the head (9FF2).
Input
IY A node
B The sentence count
Output
IY The node before it, skipping nodes marked BUT
IX The node given
B One fewer
AEC5 DEC B One sentence fewer (A012 is kept in B)
This entry point is used by the routines at AEEA and B0FD.
