C316: Scroll the text up a line, printing the line that goes if printing is on
Moves screen rows 1-17 up to rows 0-16, eight pixel lines at a time: all 32 bytes of each line in full-width mode, only the left 16 when a picture is showing (C128 set). In full-width mode the colours of rows 1-17 move up too, and before anything moves the top row goes to the ZX Printer (C3E4) if printing is on. Then row 17 is cleared with 36 (or 18) spaces. Called by the character printer at C2DF on every newline.
How it works:
1. At full width, send the top row to the printer (C3E4) if printing is on.
2. Move text rows 1 to 17 up to rows 0 to 16, eight pixel lines each, 32 bytes a line (16 beside a picture).
3. Clear the bottom text row.
Input
HL The print position
C The pixel shift
Output
The text rows moved up one line; the top row sent to the printer first when at full width
