C7A6: Check object C against requirement code A (7-15)
The second half of the requirement checks; see C628 for the codes. Each refusal goes to C632, each pass to C62F.
How it works:
1. Mask the code to its low nibble. Codes 7 to 15 split into six groups; each ends by jumping to the pass at C62F or the refusal at C632.
2. Code 7: anything will do. Code 8: the object must be in the actor's room (C821).
3. Code 9 (TAKE): in the room; in exactly one place (C8A7), so doors and the like are out; not a person (C8BE); of a size the actor can carry (C8C6); and not already held by a person (C8AF).
4. Code 10: in the room and held by the actor (D275). Code 11: in the room and in more than one place, which is what a door is. Code 12: a person anywhere. Codes 13 to 15: a person who is in the room.
Input
A The requirement code (7-15)
C The object's id
IY The action record
Output
F NZ if the object passes, Z if it is refused
