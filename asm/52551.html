CD47: Plan opcode 9, AWAIT: wait for a token from another actor
Looks along the 9FE7 list for a node left by the actor named in the argument for this actor. Fails if there is none (scripts give AWAIT a failure address pointing at itself, so the actor waits); otherwise unlinks the node, frees it and succeeds.
Input
IX The instruction (+1 the actor the token must come from)
Output
The step succeeds if the token was there (and is removed), otherwise it fails
