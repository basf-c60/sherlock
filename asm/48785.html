BE91: Check one piece of evidence (NZ if it holds)
See the case table at 9965 for the four kinds. Marks it done (bit 1 set, bit 0 clear) when it holds.
How it works:
1. If the evidence is already marked done (bit 1 of its flags), it holds: finish.
2. The top two bits of the flags give the kind. Kind 0: both things named in the record must have been seen by the player (bit 7 of their +6 flags); if so it holds. Kind $80 is a marker that only some other routine can set, so it never holds by itself.
3. Kind $40: both things must have been examined (bit 6 of +6). Then, as for kind $C0 (which has no test of its own), it holds only if it has no children, or if all of its children hold (BF08).
4. When it holds, mark it done (bit 1 set, bit 0 clear) and return NZ.
Input
IX An evidence record in the case table
Output
