F5D2: Plot the pen position in the current colour
Sets the pixel at (D, E) and gives its character cell the ink in F60B, keeping the cell's paper.
How it works:
1. Find the screen byte and bit for the pixel at (D, E) (F5FB).
2. Work out the attribute byte for that character cell.
3. Keep the cell's paper and set its ink to the pen colour at F60B. If the paper is already that colour, use the opposite ink so the pixel shows.
4. Set the pixel itself.
Input
D X coordinate
E Y coordinate
HL is preserved; A and F are not

F5D3 CALL $F5FB Call the routine "Find the screen byte and bit for the pen" (F5FB) - HL = the pixel's screen byte, A its bit (F5FB)
F5D6 PUSH AF Save AF on the stack
F5D7 PUSH HL Save HL on the stack
F5D8 LD A,H Copy H into A - Find its attribute byte ($58xx)
F5D9 AND $18 Keep only bits 3, 4 of A (mask $18)
F5DB RRCA Rotate A right one place (bit 0 goes to carry and bit 7)
F5DC RRCA Rotate A right one place (bit 0 goes to carry and bit 7)
F5DD RRCA Rotate A right one place (bit 0 goes to carry and bit 7)

F5E0 LD H,A Copy A into H
F5E1 LD A,(HL) Read the byte HL points at into A - Keep the paper, set the ink to the pen colour (F60B)
F5E2 AND $38 Keep only bits 3, 4, 5 of A (mask $38)
F5E4 LD (HL),A Store A at the address HL points to
F5E5 LD A,($F60B) Read "Fill pattern for the picture interpreter" (F60B) into A
F5E8 RLCA Rotate A left one place (bit 7 goes to carry and bit 0)
F5E9 RLCA Rotate A left one place (bit 7 goes to carry and bit 0)
F5EA RLCA Rotate A left one place (bit 7 goes to carry and bit 0)

F5F1 RRCA Rotate A right one place (bit 0 goes to carry and bit 7)
F5F2 RRCA Rotate A right one place (bit 0 goes to carry and bit 7)
F5F3 OR (HL) Set in A the bits that are set in the byte HL points at
F5F4 LD (HL),A Store A at the address HL points to
F5F5 POP HL Restore HL from the stack - Then set the pixel
