C5FC: Should the indirect object be guessed? (numbered records)
As C542 without the $A01D test, for the numbered action records (C583).
Input
$A010, $A035
Output
F NZ when the indirect object should be guessed; Z when not
C5FC LD A,($A010) Read $A010 in "Game variables" into A - Indirect object requirement code ($A010) zero: no, Z
C5FF AND A Clear the carry flag for the caller (A is unchanged)
C600 RET Z If A is zero, return
C601 LD A,($A035) Read $A035 in "Game variables" into A - Indirect object still $FF (not named)?
C604 CP $FF Compare A with $FF
C606 JR NZ,$C60B If A differs from $FF, skip ahead to C60B
C608 OR $01
C60A RET Return to the caller
C60B XOR A Set A to zero, which sets the zero flag for the caller - No: Z
C60C RET Return to the caller
