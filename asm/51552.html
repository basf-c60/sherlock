C960: Look up a numbered entry in the table at $AA71
Addresses named in the title: AA71.
Given a number in (IX+1), computes AA71 + (that number - 1)*2 and reads a 16-bit value from there - a plain, direct-indexed table lookup, not a search.
Input
IX A record whose +1 is a number
Output
HL The action record at entry (number - 1) of the table at $AA71
C960 LD A,(IX+$01) The number to look up (meaning depends on IX - see prose)
C963 LD E,A Copy A into E
C964 LD D,$00 Load D with $00
C966 LD HL,$AA71 The table's base
C969 DEC DE Step DE back one byte
C96A ADD HL,DE (number-1) * 2, added twice for a word-sized stride
C96B ADD HL,DE Add DE to HL
C96C LD E,(HL) This entry's own table value...
C96D INC HL Step HL on to the next byte
C96E LD D,(HL) ...becomes the result
C96F EX DE,HL Swap DE and HL
C970 JR $C996 Run it
