C040: Save the game to tape, then verify it
Prints a prompt taken from the ROM's tape messages (C1C0 with HL = $09A2: the ROM's 'Start tape, then press any key.', then a key is waited for), writes a 17-byte header (C0FE: a code file named 'SHD V2.0') and the block with SA-BYTES ($04C2), then asks for the tape to be rewound ('REWIND TAPE', C0A5) and verifies both with LD-BYTES ($0556) - 'TAPE ERROR' (C0B1) if they do not match.
Input
IX The start of the block
DE Its length
Output
The block saved to tape and verified
