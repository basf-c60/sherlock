A040: Start the game
The game's own entry point. Clears two flag bytes, resets the stack to 5D80 (reusing the loader's own workspace, which is no longer needed), and clears the screen.
Then it waits for a single keypress to choose New Game vs Continue: pressing 'n' or 'N' starts a new game (clears a flag at $A011); anything else leaves that flag set, and the code that follows loads state back from a table at 9860, so this is very likely also how a restored/continued game resumes its characters' positions.
Seeds a simple RNG from the Z80 refresh register (R) - a common period-accurate trick, since R free-runs on every instruction fetch and so is effectively unpredictable at the moment the player first presses a key.
From A064 on is the game's main loop - see there.
