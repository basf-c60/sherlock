C45E: Is B below the last number for this object slot?
Carry when B is below 106 if the slot's requirement code ($A010, or $A00F when entered at C463) is below 5, or below 110 if it is 5 or more - 106 and 110 being one past the last room and the last thing. Used by the guessing loops C55A and C60D.
