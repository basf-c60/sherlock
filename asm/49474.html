C142: Text lines full width again (36 characters)
Clears C128 and sets the characters-left count (C1F5) to 36, the print position to $5020 (the start of screen row 17, where every line of text is printed before the window scrolls up) and the pixel shift to 2, by joining the end of C129. It does not clear anything. Called by the page-wait at C306, by the boot set-up at C14A, and at D71D each time the player is asked for a command - which is why a picture stays up only until the text that follows the next command scrolls it away.
Output
$C1F5 36 characters to a line
$C128 0
C142 XOR A Not in narrow mode
C143 LD ($C128),A Store A in "Flag: text lines are narrow (a picture is showing)" (C128)
C146 LD A,$24 36 characters to a line
C148 JR $C133 Set the rest up as C129 does
