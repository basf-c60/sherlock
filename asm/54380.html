D46C: Find the exit from the actor's room through door A ($D46C) or to room A ($D471)
Addresses named in the title: D471.
Walks the exits of the actor's room (D33C; three-byte entries: direction, door, room, stepped by D206) comparing byte 1 (the door, entry D46C) or byte 2 (the room beyond, entry D471) with A. The offset is written into the instruction at D48B (its displacement byte $D48D) - self-modifying code. Returns IX on the exit, or A = $FF if there is none. D471 is why a room can only be named in a command when it is next door: the room search D39B lets through only rooms it finds.
Input
A A door number (entry $D46C) or a room number (entry $D471)
Output
F NZ with IX the exit if there is one; Z if not
BC, IY Kept
