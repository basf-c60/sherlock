Engine internals

How the program itself works: actor table, scripts, dispatch and printing.

  • Every fixed message, rendered by the game itselfThe message printer at A59F is a bytecode interpreter: dictionary word references, packed 5-bit letters, literal punctuation and 29 control codes.
  • Plan opcode 12 would hang the gameThe interpreter's test for opcode 12 is CP $0C / JR Z,CD08 - and CD08 is that JR Z itself, so with Z set it jumps to itself for ever.
  • A saved game on the original tapeBesides the loading screen and the game, the tape carries a third block, a CODE file called 'SHD V2.0' for 840B-$A01F.
